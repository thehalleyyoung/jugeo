Getting Started

Installation

Get JuGeo up and running in under a minute.

Requirements

  • Python ≥ 3.10 (3.11+ recommended)
  • Git for cloning the repository
  • Z3 (optional, installed automatically via z3-solver pip package)

Install from Source

JuGeo is currently distributed as a source package. Clone and install in development mode:

bash 
# Clone the repository
git clone https://github.com/thehalleyyoung/jugeo.git
cd jugeo

# Install in development mode
pip install -e .

# Verify installation
jugeo info

Verify Installation

Check that everything is working:

bash 
# Show package info and available features
jugeo info

# Run the test suite
pytest test_examples/ -v

# Run algorithm tests
python3 test_algorithms.py
Note on LLM Features

Some features (copilot evidence channel, ideation engine, foundation pipeline) use LLM calls via the Anthropic API. To use these, set your API key:

export ANTHROPIC_API_KEY="your-key-here"

You can disable LLM features with --no-llm on any CLI command. The core verification pipeline (Z3, runtime witnesses, descent) works fully offline.

Project Structure

    generation/        # Cover design, construction, inhabitant fleets
    orchestration/     # Synthesis, fleet management, semantic control
    ideation/          # Theorem discovery, novelty search
    problem_modes/     # Spec satisfaction, equivalence, bugs, repair
    cli/               # CLI commands (26 commands)

  proofs/lean/         # 93 Lean 4 proof files
  experiments/         # Experiment scripts and results
  test_examples/       # 300+ benchmark test cases
  examples/            # Example programs

Building Lean Proofs

To check the mechanized Lean 4 proofs:

bash 
cd proofs/lean
lake build

Requires Lean 4 and elan to be installed.

LLM / Copilot Integration

JuGeo integrates large language models as structured evidence channels with bounded, auditable trust. Copilots can construct proofs, suggest annotations, lower IR, run research tasks, and participate in oracle federation — always subject to the COPILOT_SUGGESTED trust ceiling.

The Copilot Trust Model

JuGeo treats LLMs not as oracles but as evidence channels in the trust algebra. Like all channels, a copilot produces evidence that is assigned a trust level, and that trust level determines how the evidence is used in descent and gluing. The key constraint is the COPILOT_SUGGESTED ceiling: evidence produced by an LLM copilot can never directly yield a trust level higher than COPILOT_SUGGESTED.

This ceiling is not a limitation — it is a safety feature. LLMs can hallucinate plausible-looking but incorrect proofs or annotations. By capping their trust, JuGeo ensures that copilot output must always be confirmed by a higher-trust channel (solver or formal proof) before it contributes to a VERIFIED judgment. Copilot evidence is best understood as a high-quality hint that dramatically reduces the search space for the solver.

⚠️

COPILOT_SUGGESTED is never sufficient for closure. A judgment cannot be closed with only copilot evidence. At least one higher-trust channel (SOLVER, ANNOTATION, or FORMAL_PROOF) must confirm the copilot's output. Use require_confirmation=True (the default) in the CopilotAgent to enforce this automatically.

The trust hierarchy relevant to copilot integration is: \[ \mathrm{NONE} \;\prec\; \mathrm{COPILOT\_SUGGESTED} \;\prec\; \mathrm{ANNOTATION} \;\prec\; \mathrm{SOLVER} \;\prec\; \mathrm{FORMAL\_PROOF} \]

Copilot Roles (Papers 86–98)

The copilot integration covers nine distinct roles, each explored in a dedicated paper. On the website, these roles describe the architecture and connect to the stable public surfaces: CLI model selection, jugeo.easy, and the coding-agent adapters documented in jugeo-agents.

Construction

Generate proof terms, lemma statements, and annotation templates from natural-language descriptions of the intended invariant.

Deduction

Apply inference rules step-by-step to advance a proof state. Uses chain-of-thought prompting to produce structured deduction traces.

Evidence Channels

Copilot as a first-class evidence channel with structured output schema, provenance tagging, and automatic CHALLENGE generation on conflict.

Oracle Federation

Multiple copilot instances federated as an oracle ensemble. Majority vote or trust-weighted combination resolves disagreements.

Advisors

Domain-specialist advisor agents (security, performance, API design) that annotate judgments with domain-specific concerns.

Research

Long-horizon research tasks: literature search, analogical reasoning, hypothesis generation, and novelty assessment for new theorems.

IR Lowering

Translate high-level semantic judgments into SMT-LIB or Lean IR, closing the gap between natural-language specs and machine-verifiable formulas.

Lifecycle

Manage the full verification lifecycle: triage open judgments, schedule work, generate status reports, and coordinate handoffs to human reviewers.

Specialised Copilots

Trust algebra advisor, doctrine reviewer, cover designer, theorem assistant, and diagnostic summariser — each targeting a specific sub-system of JuGeo.

Evidence Channel Protocol

The current public JuGeo surface for model-backed workflows is the CLI plus jugeo.easy. Those tools still fit the same evidence-channel story, but the stable way to use them today is to run a model-backed command and inspect the structured output it returns.

python 
import subprocess

completed = subprocess.run(
    ["python3", "-m", "jugeo", "research", "Find likely verification gaps in this module"],
    check=True,
    capture_output=True,
    text=True,
)

print(completed.stdout)

Oracle Federation

Oracle federation allows multiple copilot instances to be combined into a single high-reliability oracle. Each copilot in the federation independently answers the same query, and the federation protocol aggregates their responses into a single evidence artifact with a combined trust score.

The federation uses one of three aggregation modes:

  • MAJORITY — the answer held by a majority of copilots wins. Trust is COPILOT_SUGGESTED only if all agree; otherwise NONE.
  • TRUST_WEIGHTED — each copilot has a prior reliability weight; answers are weighted by reliability score.
  • CONSERVATIVE — only accept an answer if all copilots agree. Highest precision; lowest recall.
python 
from jugeo.evidence.trust import TrustAlgebra, TrustLevel

algebra = TrustAlgebra()

solver_checked = TrustLevel.SOLVER_DISCHARGED
copilot_hint = TrustLevel.COPILOT_SUGGESTED

print(algebra.meet(solver_checked, copilot_hint))
print(algebra.join(solver_checked, copilot_hint))

Lifecycle Management & Advisors

The Lifecycle copilot manages the end-to-end verification workflow for a codebase. It triages open judgments, schedules verification work according to priority (backpressure score, deadline, developer assignment), generates status reports, and coordinates handoffs between automated and human-in-the-loop steps.

Advisor copilots are specialist agents that annotate judgments with domain expertise. Current built-in advisors:

  • SecurityAdvisor — flags potential injection, overflow, and privilege escalation issues.
  • PerformanceAdvisor — identifies quadratic patterns, excessive allocation, and lock contention.
  • APIDesignAdvisor — suggests interface improvements that would reduce H¹ obstructions at API boundaries.
  • DocAdvisor — generates docstring annotations that can be verified by the solver.
python 
import subprocess

bugs = subprocess.run(
    ["python3", "-m", "jugeo", "--format", "json", "bugs", "src/example.py"],
    check=True,
    capture_output=True,
    text=True,
)
repair = subprocess.run(
    ["python3", "-m", "jugeo", "--format", "json", "repair", "src/example.py"],
    check=True,
    capture_output=True,
    text=True,
)

print(bugs.stdout)
print(repair.stdout)

Python Examples

Using the IR lowering copilot to translate a natural-language spec:

python 
from jugeo.easy import research

report = research(
    "Lower this pricing invariant into a solver-friendly verification plan",
    max_iterations=4,
    max_pivots=1,
    no_llm=True,
)

print(report)
